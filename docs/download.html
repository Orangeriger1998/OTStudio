Download

Every file comes from the GitHub Releases pages of the two repositories. The version and size below are read from GitHub when this page opens; the links on the right of each file lead to its SHA-256 checksum.

Android phone

Latest releaseRelease notes
  • OT-Studio-x.y.z.apk on the Releases page

Requirements. Android 10 or later and an internet connection. Chat on the phone works best with 8 GB of memory and needs about 2.4 GB of space for the model.

  1. On your phone, download the newest OT-Studio-x.y.z.apk.
  2. Open the downloaded file. Android asks whether your browser or file app may install apps. Allow it for this one install.
  3. Tap Install, then Open.

The Play Store does not list OT Studio, so updates also come from the Releases page. A newer APK installs over the old one and keeps your history, your LoRA library, and your keys. Every release is signed with the same key; a build signed with another key cannot update the app.

Windows desktop

Latest releaseRelease notes
  • OTStudio-PC-Setup-x.y.z.exe on the Releases page

Requirements. Windows 10 or 11, 64-bit. For the Chat tab with a private model, Ollama on the same PC.

  1. Download OTStudio-PC-Setup-x.y.z.exe and run it.
  2. If Windows SmartScreen warns about an unrecognized app, compare the file's checksum with the .sha256 file first, then choose More info and Run anyway.
  3. Install over an earlier version. Your keys, history, chat, and LoRAs stay.

Keys are encrypted for your Windows account. Data lives in %APPDATA%\OT Studio.

Linux desktop

Latest releaseRelease notes
  • OTStudio-PC-x.y.z-x86_64.AppImage and OTStudio-PC-x.y.z-amd64.deb on the Releases page

Requirements. A 64-bit desktop Linux with GTK 3 and a keyring service (GNOME Keyring or KWallet, which Linux Mint, Ubuntu, Fedora, and KDE desktops run by default). Tested on Linux Mint 22.

AppImage. One file that runs where it is.

chmod +x OTStudio-PC-x.y.z-x86_64.AppImage
./OTStudio-PC-x.y.z-x86_64.AppImage

An AppImage needs FUSE 2. Linux Mint has it; on Ubuntu 22.04 and later install it with sudo apt install libfuse2t64 (or libfuse2 on older releases).

Debian package. Installs to /opt/OT Studio and adds OT Studio to your menu under Graphics.

sudo apt install ./OTStudio-PC-x.y.z-amd64.deb

The first start may ask the keyring to unlock, so OT Studio can store your keys there. Data lives in ~/.config/OT Studio. A line or two about GLib in the terminal is harmless.

OT Studio LoRA Trainer Windows tool

Latest releaseRelease notes
  • OT-Studio-LoRA-Trainer.exe on the Releases page

A small Windows program that builds a photo set on your computer and starts a LoRA training run in your own Replicate account. The phone app and the desktop app can also train from their LoRA libraries, so most people never need it. It reads your Replicate token from hidden input or an environment variable and never saves it.

Checking a download

Each file has a companion .sha256 file with its checksum. The checksum confirms that the file on your disk is the one that was published.

Windows (PowerShell or Command Prompt)

certutil -hashfile OTStudio-PC-Setup-x.y.z.exe SHA256

Linux (in the folder with both files)

sha256sum -c OTStudio-PC-x.y.z-amd64.deb.sha256

On Android, a file manager with a checksum feature, or a desktop computer, can check the APK the same way.
