OT Studio for Windows and Linux

The desktop version of the OT Studio Android app. It keeps its own version numbers and its own repository, and it shares LoRA files and the same way of thinking about keys with the phone app.

Three tabs

Chat

Ask for pictures and videos in plain words. A private model in Ollama on your PC, or a model on OpenRouter, reads the messages and writes a plan: the action, the shape, the length, and the prompt words. The app picks the media, the service, the model, and the settings, and nothing is billed until you click Go.

Pictures

Choose a service and a model, describe the picture, change any setting you care about, and click Make the picture. The simple view shows the main settings for each model; Show all settings shows the rest. Each finished picture has Edit, Expand, Upscale, and Make a video.

Videos

The same steps, with a starting picture, an ending picture, or both. OpenRouter videos can take several minutes, and OT Studio checks on them every 30 seconds, even after you close the app. Make it longer continues a finished video from its last frame and joins the parts.

What it does

  • Three services, three keys. Pictures and videos from Replicate, SpicyAPI, and OpenRouter. You only need keys for the services you plan to use.
  • Pictures as references. Editing models such as Seedream 4.5, Qwen Image Edit Plus, and FLUX Kontext take pictures. Seedream 4.5 takes up to 14. Every picture gets a label, @img1, @img2, and so on, that you can use in the description.
  • Edit, Expand, Upscale. Edit a picture from a plain instruction. Expand gives it a new shape, such as wide or tall, with FLUX Fill dev painting the new area and OT Studio rebuilding the picture at full size on your PC. Upscale makes it two or four times larger with Real-ESRGAN.
  • History. Save, Open folder, Repeat, and Delete on every card. Repeat fills the form with the same model, prompt, settings, and pictures.
  • LoRAs. Use, import, export, and train FLUX dev LoRAs for faces and styles, or Qwen Image LoRAs with the alternate trainer. The files are shared with the Android app.
  • Any other service. Paste the provider's curl, Python, or Node example, say what each field is, and save it. OT Studio reads the example as text and never runs it. Exported services can be shared and never contain a key.
  • One request, sent once. A paid request is never repeated on its own. If the connection breaks after sending, the job says Outcome unknown, because the service may have done the work.
  • Approved hosts only. Only the main process reaches the network, over https, to the services' own hosts and the addresses you allowed in a dialog. The window never talks to the internet.

On Windows

One installer, OTStudio-PC-Setup-x.y.z.exe. Install it over an earlier version and your keys, history, chat, and LoRAs stay. Windows encrypts the keys for your account. Data lives in %APPDATA%\OT Studio, and saved results go to your Pictures or Videos folder, in an OT Studio folder.

On Linux

An AppImage that runs where it is, or a .deb package that installs to /opt/OT Studio and adds a menu entry under Graphics. Your keys are stored in the desktop keyring through libsecret, the same place your browser keeps its passwords. Data lives in ~/.config/OT Studio. Tested on Linux Mint 22 with Cinnamon.

Build from source

You need Node.js 24 or later. The tests cover the parts with no Electron types.

git clone https://github.com/Orangeriger1998/OTStudio-PC.git
cd OTStudio-PC
npm install
npm test
npm start            # run it
npm run dist         # Windows installer, in dist/
npm run dist:linux   # AppImage and .deb, in dist/

Picture work uses sharp and video work uses the bundled ffmpeg, both unpacked from the application archive at build time. The app is Electron; the window is plain HTML, CSS, and JavaScript with no framework, sandboxed, with a strict Content Security Policy.
