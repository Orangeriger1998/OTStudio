# Contributing to OT Studio

Thank you for helping. Bug reports and ideas are welcome as GitHub Issues. Code changes are welcome as pull requests.

If you disagree with point 3, say so in the pull request before it is merged. Your change can still be discussed as an idea.

## Before you send a change

- Run the checks in the README's "Build from source" section, and make sure they pass.
- Keep the black Material 3 look and the helpers in `Ui.kt`.
- Follow the writing rules in `CLAUDE.md` for any text a user will read.
- Never commit an API key, a signing key, or `local.properties`.
- When a screen changes, update its design page in the wiki.
